How to estimate the parameters

First-order system:

y(t) = K(1 − e−t/τ)
At t = τ, the output reaches approximately 63.2% of its final value.

Estimate K from the final output value, and estimate τ from the time at which the output reaches 63.2% of that value.

Second-order system:

Mp = e−ζπ/√(1−ζ²)
tp = π / (ωn√(1−ζ²))

For an underdamped step response, estimate ζ using the percentage overshoot, then estimate ωₙ using the peak time.
