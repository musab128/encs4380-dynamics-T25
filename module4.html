How to estimate parameters

First order — step / sine

Step: y(t) = K(1 − exp(−t/τ)). Read final value for K, then find the time to reach 63.2% of it for τ.

Sine: M = 1/√(1+(ωτ)²), φ = −atan(ωτ). Phase lag and attenuation reveal τ and K.

Second order — step

For an underdamped sensor: PO = 100 exp(−πζ/√(1−ζ²)); tₚ = π/(ωₙ√(1−ζ²)).

For critical or overdamped responses, use the overall speed and absence of overshoot to estimate parameters.

Scoring: each parameter earns up to 50 points. An error of 10% or less earns all 50 for that parameter. Larger relative errors earn fewer points. The running score lasts for this page session.
