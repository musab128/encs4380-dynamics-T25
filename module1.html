Error fraction on a log axis

For a step input, the error fraction is E(t) = e−t/τ. The log of this fraction is a straight line: ln(E) = −t/τ.

What the plots mean

Step: The output approaches KA gradually. At τ it reaches 1 − e−1 ≈ 63.2% of KA; at 3τ, 1 − e−3 ≈ 95.0%.

Ramp: For x(t) = At, the exact zero-initial-condition response is y(t) = KA[t − τ(1 − e−t/τ)]. At long times, the output behaves like the input shifted right by τ and scaled by K. Input–output steady-state error is meaningful as Aτ when K = 1; for general K, compare output to the desired gain-scaled input Kx(t), giving steady-state error KAτ.

Log error: The plot uses a logarithmic y-axis. The slope −1/τ refers to ln(E) against time, not the slope of E on ordinary linear axes.
