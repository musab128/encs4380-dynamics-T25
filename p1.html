How to explore

Start with P-only (Ki = 0 and Kd = 0), then add integral action to reduce steady-state error. Try derivative action to see how it changes transients. Keep an eye on actuator saturation.

u(t) = Kp e(t) + Ki ∫e(t)dt + Kd de(t)/dt
