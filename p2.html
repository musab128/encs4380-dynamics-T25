P2: Slow Sensor in the Loop

Adjust the feedback sensor delay τs and compare what the plant really does with what the controller is able to measure.

Feedback loop with a slow sensor

Setpoint r(t)→ + Σ − →PID→Plant→ y(t)→Sensor 1/(τs s+1)↩ measured feedback

The controller sees only the delayed sensor output m(t), not the true plant output y(t). The model integrates τs dm/dt + m = y alongside the plant.

Controls

Plant: τ dy/dt + y = u (K = 1)
Sensor: τs dm/dt + m = y
Error: e = setpoint − m

Predict, then check

What does sensor delay change?

With a slow sensor, the controller can keep increasing the command while the real plant has already passed the target. Increase τs and watch the real output overshoot or oscillate—even if the measured signal looks delayed and smoother.

For some gain settings the loop may become unstable or fail to settle. This is expected behavior, not a plot error.
